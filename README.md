# LF_Compiler

A compiler for the esolang LF. Lightweight and efficent.

## Features
- Simple and lightweight compiler.
- Easy to set up and run.

## Installation
To use this compiler, clone the repository to your local machine:
```bash
git clone https://github.com/alphamain407-max/LF_Compiler
```

## Usage
Open the `index.html` file in your browser to run the website.
